Project uses TypeScript with ES modules and a small feature-based structure. Naming is straightforward: kebab-case for feature directories/change names, PascalCase for classes like `FeatureRegistry`, and camelCase for functions/constants unless constants are true fixed identifiers. Existing content-script code prefers small top-level helpers, explicit DOM selector lists, inline style assignment for injected UI, and minimal comments. OpenSpec artifacts and documentation are written in English.
