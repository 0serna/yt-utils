Main development commands:\n- `npm run build` — production build into `extension/`\n- `npm run dev` — watch build\n- `npm run typecheck` — TypeScript type checking\n- `openspec list --json` — list OpenSpec changes\n- `openspec status --change "<name>" --json` — inspect change artifact status\n- `openspec instructions <artifact> --change "<name>" --json` — fetch artifact instructions\n- Load `extension/` as an unpacked extension in `chrome://extensions` after building.
